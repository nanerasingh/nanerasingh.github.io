📶 NetworkCCX

Control Center Cellular & Location Toggles Module

✨ Description

NetworkCCX brings advanced Control Center network toggles to quickly switch between 5G Auto, 5G On, LTE, Wi-Fi, and Location Services directly from your CC modules.

📸 Screenshots
🚀 Features
  • Cellular Mode Switcher: Switch between 5G Auto, 5G On, and LTE directly from Control Center.
  • Location Services Toggle: Quick tap to enable or disable Location Services system-wide.
  • Live Module Icons: Dynamic icons showing live state changes and haptic feedback.
  • CCSupport Integrated: Full support for CCSupport on rootless & rootful environments.
📱 Compatibility
iOS / iPadOS iOS 14.0 – 16.x
Jailbreaks Rootless (Dopamine, palera1n) & Rootful
Dependencies CCSupport, PreferenceLoader
