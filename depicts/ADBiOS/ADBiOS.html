🚀 ADBiOS

Android Device Manager & ADB Utility for Jailbroken iOS

✨ Overview

Manage your Android device directly from your Jailbroken iPhone over ADB!

Welcome to the first official release of ADBiOS. This application empowers power-users to manage, tweak, and debug their Android devices straight from iOS using a sleek, native interface.

📸 Screenshots
🎉 What's New in v1.0 (Initial Release)

📊 Dashboard Redesign

  • System Overview: Clean visual interface showing real-time stats for the connected Android device.
  • Hardware Status: Live progress bars indicating current battery capacity and storage usage.
  • Network & Connections: Instantly view whether Wi-Fi, Bluetooth, and crucial radios are enabled.

📂 Enhanced File Explorer (ES Explorer Style)

  • Redesigned UI: Highly visual file manager drawing inspiration from classic tools like ES File Explorer.
  • Path Breadcrumbs: Sticky breadcrumb path header so you never lose your place while browsing the Android filesystem.
  • Smart Parsing & Fallbacks: Ensures directories load properly with raw fallback views if directory permissions block standard parsing.

📱 Advanced App Management (Root & Non-Root)

  • Standard Actions: Launch app, force stop, clear standard app data, and uninstall.
  • Root Privileges (New!): If your Android device is rooted, unlock advanced actions:
    • Freeze & Unfreeze applications
    • Enable & Disable system apps
    • Deep Clear App Data (su -c pm clear)
    • Uninstall System Apps (Debloat your Android device effortlessly!)

🖥️ Root Terminal & Shell Macros

  • Interactive Shell Page: Features categorized visual macros for instant command execution.
  • Root-Only Command List: Quick root-only commands (e.g. su -c setenforce 0, reboot bootloader, restarting system services) without manual typing.
🛠️ Installation & Setup Instructions
  • SpringBoard: Respring your device if prompted.
  • Android Setup: Ensure target Android device has Wireless Debugging enabled or is connected to the same network running ADB on port 5555.
