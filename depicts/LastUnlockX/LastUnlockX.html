🔓 LastUnlockX

Last Unlocked Timestamp & Lockscreen Security Log Tweak

✨ Description

LastUnlockX displays your device's last unlocked timestamp, time elapsed since previous unlock, and security info right on your Lock Screen or Status Bar.

📸 Screenshots
🚀 Features
  • Last Unlocked Timestamp: Display exact date and time when the device was last unlocked.
  • Lock Screen Integration: Display on Lock Screen header or Status Bar.
  • Security Log: Monitor unlock events and failed attempt counts.
  • Custom Formatting: Change font style, colors, and date string format.
📱 Compatibility
iOS / iPadOS iOS 14.0 – 16.x
Jailbreaks Rootless (Dopamine, palera1n) & Rootful
