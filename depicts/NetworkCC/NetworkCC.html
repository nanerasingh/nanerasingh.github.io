NetworkCC

4G/5G & Location Services Control Center Modules

iOS 14+ arm64 Rootless CCSupport Free

Included Modules

NetworkCC — 4G/5G Toggle

Switch your cellular radio between LTE, 5G, and Auto directly from Control Center. No digging into Settings → Cellular → Voice & Data.

LocationCC — Location Services Toggle

Enable or disable system-wide Location Services with a single tap in Control Center. Live status indicator shows current state.

NetworkCC — Tap Actions

Tap ModeBehaviourKey
Cycle All 3 Rotates Auto → 5G On → LTE on each tap 0
5G Auto Toggles between 5G Auto and LTE 1
5G On Toggles between 5G On and LTE 2
LTE Only Forces LTE, no 5G 3

Tap action is configurable in Settings → NetworkCC. Uses private _CTServerConnectionSetRATSelection API.

LocationCC — Features

  • Reads current Location Services state on load via CLLocationManager
  • Polls state periodically — icon updates live if another app changes it
  • Calls setLocationServicesEnabled: to toggle system-wide
  • Custom pin-style icon drawn in code — fits native CC aesthetic
  • Exception-safe: catches CLLocationManager errors gracefully
