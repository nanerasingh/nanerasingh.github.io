✨ TheosManagerPro

All-in-One GUI for Local Theos Workflow Management

✨ What is TheosManager?

TheosManager is an all-in-one GUI for managing Theos workflows locally on jailbroken devices. It automates repetitive setup steps like writing Makefiles, generating bundle resources, configuring Darwin notifications, and running build commands with real-time log tracking.

🚀 Core Features
🛠️ Comprehensive Project Scaffolding
  • Tweaks: Generates clean Logos (Tweak.x) templates with SpringBoard/app filter plists.
  • Standalone Applications: Creates full application structures with main.m, AppDelegate, RootViewController, default application icons, and an embedded entitlements.plist.
  • Control Center Modules: Generates CCUIToggleModule bundles with aggregate makefile hierarchies and proper install destinations.
  • Command-Line Tools & LaunchDaemons: Generates daemon entry points, layout launch plists, and executable directories.
⚙️ Automated Preference Bundle Generator
  • Visually build and configure Settings panels (RootListController, Root.plist).
  • Built-in support for standard specifiers (PSSwitchCell, PSSliderCell, PSLinkListCell, etc.) as well as third-party cells like Alderis Color Picker and Cephei.
  • Auto-generates Darwin notification listeners (<PackageID>/Reload) and preference-reading code.
💻 Smart Compilation & Log Viewer
  • Interactive log terminal running make package via local subprocesses.
  • Filters out messy ANSI escape color codes, directory timestamps, and noise.
  • Clean, stage-by-stage status indicators for Compiling, Linking, Stripping, Signing, and Packaging.
📦 Flexible Deployment
  • 🔥 "Make Do" Mode: One-tap action that builds the project, installs the .deb locally via root execution, and performs a clean respring or uicache refresh.
  • 📡 Remote SSH Deployer: Transfer and install .deb packages over local Wi-Fi to secondary test devices via scp/ssh.
  • 📤 Share Sheet Integration: Quick-share .deb outputs directly to Sileo, Zebra, Filza, or AirDrop.
🏗️ Architecture Support
  • Built with native support for both Rootless (/var/jb, Dopamine) and legacy Rootful jailbreak environments on iOS 14 through iOS 16+.
📱 Compatibility & Requirements
iOS / iPadOS iOS 14.0 – 16.x
Jailbreaks Rootless (Dopamine, palera1n) & Rootful
Requirements Theos (/var/jb/opt/theos or /opt/theos), clang, make, ldid, dpkg-deb, sudo
