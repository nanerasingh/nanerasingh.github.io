📶 LocationApp

The WiFi App Manager — Automatic App State Management for iOS

✨ Overview

LocationApp is a powerful rootless iOS tweak that automatically manages and changes state of your selected applications based on your WiFi connection state. Perfect for managing specific apps when connected to work, school, or public networks.

🎉 What's New in v1.1

🎨 Completely Revamped Preferences UI

  • Dynamic Master Switch: The "Enable LocationApp" toggle features buttery-smooth animations that dynamically expand or collapse the rest of the settings when toggled.
  • Modern Aesthetic: Integrated a beautiful LastUnlockX-style header banner with sleek gradients, glowing effects, and a custom transparent square icon scaled for modern iOS Settings.
  • Streamlined Actions: Added quick action buttons for Reset Defaults, Respring, and direct developer support options (Twitter/Email).

🛠️ Smarter Action Log & System Health

  • Action Log Redesign: The Log Viewer intelligently groups logs by application. Clearing logs preserves the single most recent entry for each actively managed app, keeping your history organized and clutter-free.
  • System Health Integration: Moved System Health checks directly into the primary SSH Helper UI for an instant, one-glance view of daemon and root environment status.

⚙️ Under-the-Hood Improvements

  • Robust WiFi Scanning: Improved parsing for modern iOS (15/16+) known-networks.plist formats to seamlessly list and manage your saved SSIDs.
  • Daemon Reliability: Replaced blocked system() calls with native posix_spawn integrations for rock-solid background app renaming (.app ↔ .appp), SSH key generation, and uicache execution without SpringBoard crashes.
  • Rootless Optimized: Fully compiled and tailored for modern rootless jailbreak environments (Dopamine / Palera1n).
📦 Installation & Setup Notes
  • Configuration: Go to Settings > LocationApp to setup your managed apps and blacklisted WiFi networks.
  • First Time SSH Setup: If setting up SSH actions for the first time, visit the SSH Helper page in the settings to run the background setup.
